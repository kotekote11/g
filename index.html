Как пользоваться. Вводите значение в любое поле — остальные пересчитываются мгновенно. Для программистов ключевые значения вынесены наверх: DMX (для DMX_Piano) и Гц.
Привязка. DMX охватывает весь токовый диапазон: DMX = ROUND(255 · I / 20) (0 мА → 0, 20 мА → 255). Проценты — участок 4…20 мА: P = (I − 4)/16, % = 100·P.
Частота считается прямо из DMX: Гц = ROUND(Pr.02 + (Pr.01 − Pr.02)·(DMX − 51)/204), то есть DMX 51 (4 мА) → 0 Гц, DMX 255 (20 мА) → Pr.01. При Pr.01 = 50 Гц и Pr.02 = 0 это ваша формула ROUND(DMX·0,245098039 − 12,5): 1 ед. DMX ≈ 0,245 Гц, 1 Гц ≈ 4,08 ед. DMX. Значение частоты целое (как в DMX_Piano), ниже строки показано точное значение по шкале.
Ниже 4 мА (DMX меньше 51) частота равна Pr.02, проценты = 0, DMX продолжает уменьшаться до 0.
Точность. 1 ед. DMX = 20/255 = 0,0784 мА = 0,245 Гц (при 50 Гц макс.). Дискретность выхода 4_СС (12 бит) — около 0,005 мА, то есть ток задаётся точнее, чем шаг DMX.
Подключение. Выход 4_СС (0–20 мА) → аналоговый вход VFD-EL в режиме токового сигнала (ACI); при 4…20 мА рабочий участок 0…100 % частоты, при токе ниже 4 мА преобразователь держит минимальную частоту.
Pr.4.18 (лимит максимума). Параметр занижает верхнюю частоту: f_макс = Pr.01 · 4.18 %. Шкала DMX остаётся линейной, но точка DMX 255 (20 мА) даёт уже не 50 Гц, а Pr.01 · 4.18 %; значения 4.18 % и DMX при этом не меняются — меняется только цена одного шага.
Высота струи. Для лопастных насосов высота примерно пропорциональна квадрату частоты: H₂ ≈ H₁·(f₂/f₁)², поэтому 4.18 % = 100·√(H_цель / H_при_100 %). Пример: при 4.18 = 100 % струя 12 м, цель 6 м → √(6/12) = 0,71 → 4.18 ≈ 70,7 %, максимум 35,4 Гц. Зависимость приближённая: меняйте параметр шагами, после каждого шага замеряйте высоту линейкой и уточняйте 4.18; следите за током двигателя и не превышайте паспортных значений.
